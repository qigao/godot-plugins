# GDMP Demo source

The Godot project comes from [GDMP-demo at `b70fdf9`](https://github.com/j20001970/GDMP-demo/tree/b70fdf9b9bdcac4447fc09dcf139ef2ed720e98e/project). Its scenes, scripts, project settings, and tests are preserved as upstream published them under the [MIT license](LICENSE).

This source snapshot retains the upstream Godot 4.7 project settings. The bundled upstream add-ons and prebuilt native libraries are excluded. Upstream uses GDMP, CameraServerExtension, FileAccessWeb, and GUT. The demo still needs to be adapted for this repository's Godot 4.5.2, in-tree GDMP, and Salts Camera before it can run with those add-ons.
